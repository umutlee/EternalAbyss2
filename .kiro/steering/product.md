# Deep Abyss Hive (深渊巢穴)

Deep Abyss Hive is an innovative RTS game combining idle mechanics, genetic evolution, and MMO potential. The project is currently in Phase 3.2 of a service-oriented refactoring plan.

## Core Concept
- **Genre**: Idle RTS + Genetic Evolution + MMO potential
- **Theme**: Alien hive management with creep expansion and unit evolution
- **Innovation**: Gene fusion system, dynamic mutation, player-driven genetic marketplace

## Key Features
- **Hive Management**: Mother nest upgrades, creep expansion, building layout optimization
- **Unit Evolution**: Base unit hatching, evolutionary branches, rare mutation variants
- **Genetic System**: Gene sequence collection, fusion experiments, dynamic evolution trees
- **Multi-layered Maps**: Surface, underground, and aerial exploration layers
- **Dynamic Events**: Environmental disasters, resource opportunities, terrain changes

## Current Status
The project is undergoing a major service-oriented refactoring to improve modularity and maintainability. The codebase is being restructured from monolithic managers to service-based architecture with dependency injection.

## Target Audience
Players who enjoy strategic depth, progression systems, and creative experimentation with genetic combinations in a persistent world environment.
