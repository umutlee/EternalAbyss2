# QA Smoke Guide (3 minutes)

## Steps
1. Play, watch Console: Managers created; GameConfig summary; Terrain streaming.
2. Press F6 to spawn units (log "Units: spawned"); press F10 to batch dispatch.
3. Press B for building placer; preview color reacts to rules; place then ensure object layer is Building; Delete/F8 removes it.
4. Smart Console: toggle categories, Solo, Search; HUD is draggable and persists position.
5. HEALTH: per healthLogInterval prints fps/mem/counts (if enabled).
