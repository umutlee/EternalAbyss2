# 深渊巢穴 - 建筑系统设计文档

## 1. 概述

建筑系统是《深渊巢穴》游戏的核心系统之一，负责管理玩家在游戏世界中建造、升级和操作各种建筑。本文档详细描述了建筑系统的设计、数据结构、接口定义和实现细节。

## 2. 系统目标

- 实现多样化的建筑类型，支持不同功能和用途
- 支持建筑与菌毯系统的深度集成，实现菌毯依赖机制
- 提供灵活的建筑升级路径，支持多种进化方向
- 实现高效的建筑管理和交互机制
- 支持大规模建筑场景，保持良好性能

## 3. 建筑类型设计

### 3.2 建筑功能分类

按功能可将建筑分为以下几类：

1. **核心建筑**
   - 母巢（Hive）：主要生产建筑，可生产工作单位，是玩家的核心建筑

2. **生产建筑**
   - 孵化池（SpawningPool）：生产基础战斗单位
   - 进化室（EvolutionChamber）：生产进化型单位
   - 突变室（MutationChamber）：生产高级变异单位

3. **研究建筑**
   - 基因库（GeneBank）：解锁基础科技和升级
   - 突变室（MutationChamber）：解锁高级突变科技

4. **资源建筑**
   - 资源处理器（ResourceProcessor）：收集和处理基础资源
   - 生物能核心（BioEnergyCore）：产生生物能，支持建筑和单位运作

5. **防御建筑**
   - 防御塔（DefenseTower）：基础防御建筑，攻击范围内敌人
   - 孢子塔（SporeTower）：远程攻击建筑，可攻击空中单位
   - 黏液池（SlimePit）：减速敌人的防御建筑，造成持续伤害

6. **功能建筑**
   - 菌毯节点（CreepNode）：扩展菌毯覆盖范围
   - 地下通道（Tunnel）：允许单位快速在两点间移动
   - 感知节点（SensingNode）：提供视野和侦察能力

    // 状态信息

    public float ConstructionProgress;
    public float ConstructionTime;

    // 资源信息

### 4.3 ProductionQueueItem

```csharp
public struct ProductionQueueItem
{

    public float TotalTime;      // 总生产时间
}
```

## 6. 建筑管理器接口

IBuildingManager接口定义了建筑系统的核心功能：

```csharp
public interface IBuildingManager : IManager
{
    // 建筑创建和销毁
    int CreateBuilding(BuildingType type, Vector3 position, Quaternion rotation, int ownerId);

    // 建筑查询
    BuildingData GetBuildingData(int buildingId);

    BuildingState GetBuildingState(int buildingId);
    
    // 建筑升级
    bool UpgradeBuilding(int buildingId, string upgradePath);
    float GetUpgradeProgress(int buildingId);
    
    // 生产管理
    bool AddToProductionQueue(int buildingId, ProductionQueueItem item);
    bool RemoveFromProductionQueue(int buildingId, int queueIndex);
    ProductionQueueItem[] GetProductionQueue(int buildingId);
    
    // 研究管理
    bool StartResearch(int buildingId, string researchId);
    bool CancelResearch(int buildingId);
    ResearchItem GetCurrentResearch(int buildingId);
    
    // 建筑与菌毯交互
    bool IsOnCreep(int buildingId);
    float GetCreepCoverage(int buildingId);
    
    // 建筑能量管理
    float GetBioEnergyConsumption(int buildingId);
    float GetBioEnergyGeneration(int buildingId);

}
```

## 7. 建筑与菌毯交互

建筑系统与菌毯系统深度集成，实现以下交互机制：

1. **菌毯依赖**：大多数建筑需要建造在菌毯上，离开菌毯会进入离线状态
2. **菌毯扩张**：菌毯节点可以扩展菌毯覆盖范围
3. **能量传输**：菌毯作为能量网络，连接生物能核心和其他建筑
4. **建筑加成**：建筑在菌毯上获得额外加成效果

## 8. 建筑升级系统

建筑升级系统支持多种升级路径，每种建筑可以沿不同方向进化：

1. **线性升级**：简单提升建筑的基础属性和效率
2. **分支升级**：建筑可以向不同方向进化，获得特殊能力
3. **突变升级**：通过消耗基因点，建筑可以获得独特的突变特性

升级路径通过UpgradePath类定义：

```csharp
public class UpgradePath
{
    public string PathId;
    public string Name;
    public string Description;
    public BuildingType SourceType;
    public BuildingType TargetType;
    public Dictionary<string, float> ResourceCosts;
    public float UpgradeTime;
    public List<string> UnlockedAbilities;
    public Dictionary<string, float> AttributeModifiers;
}
```

## 10. 实现细节

### 10.1 建筑放置系统

建筑放置系统负责处理建筑的放置逻辑：

1. **位置验证**：检查建筑位置是否有效（无碰撞、在菌毯上等）
2. **资源检查**：验证玩家是否有足够资源
3. **建筑创建**：创建建筑实例并初始化
4. **建造过程**：管理建筑的建造进度

### 10.2 建筑更新系统

建筑更新系统负责处理建筑的状态更新：

1. **状态管理**：根据条件更新建筑状态
2. **生产处理**：处理生产队列中的项目
3. **研究进度**：更新研究进度
4. **能量管理**：计算能量消耗和产出
5. **菌毯检查**：验证建筑是否在菌毯上

### 10.3 建筑与其他系统的交互

建筑系统与其他系统的交互接口：

1. **与单位系统**：生产单位、提供单位升级
2. **与菌毯系统**：扩展菌毯、检查菌毯覆盖
3. **与资源系统**：消耗和产出资源
4. **与科技系统**：解锁新建筑和升级

## 11. 性能优化

为确保建筑系统在大规模场景中保持良好性能，采用以下优化策略：

1. **空间索引**：使用空间索引系统快速查找区域内的建筑
2. **批量更新**：对相似建筑进行批量状态更新
3. **LOD系统**：根据距离调整建筑模型和效果复杂度
4. **延迟更新**：非关键更新使用时间间隔或条件触发
5. **数据缓存**：缓存频繁访问的建筑数据

## 12. 总结

建筑系统是《深渊巢穴》游戏的核心系统之一，通过多样化的建筑类型、灵活的升级路径和与菌毯系统的深度集成，为玩家提供丰富的策略选择和游戏体验。本文档详细描述了建筑系统的设计、数据结构、接口定义和实现细节，为开发团队提供了清晰的实施指南。
