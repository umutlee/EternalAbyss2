一、架构总览
- Core
  - Config: BaseConfigSO / ConfigManager / ConfigUtility
  - Interfaces: IManager / IService / IUpdatable / ISpatialIndex（Obsolete，转至 SpatialIndex.Interfaces）
- SpatialIndex
  - Implementations: OctreeSpatialIndex / QuadTreeSpatialIndex / SimpleSpatialIndex
  - Services: SpatialIndexService（Initialize 改以 Bounds 注入世界边界）
  - Data: SpatialIndexPerfSnapshot（旧版快照）/ SpatialIndexPerformanceStats（运行时统计）
  - Compat: SpatialIndex_LegacyAdapter、List/Query 兼容层（仍有 TODO）
- Buildings
  - Enums: BuildingState（替换 Compat 常量）
  - Services/Managers：建设、查询、研究（部分 TODO）
- Creep / Terrain / Units
  - 兼容层与核心接口逐步收敛，保留 TODO 以分阶段落地

二、核心流程（更新）
初始化顺序（无场景依赖，代码驱动）:
1) 加载配置（Core/Config）
2) 注册服务（ServiceManager）
3) 初始化空间索引
```csharp
var svc = new SpatialIndex.Services.SpatialIndexService();
svc.Initialize(new Bounds(Vector3.zero, Vector3.one * 1000f));
```
4) 按需注册 Buildings/Creep/Terrain 等系统，进入 Update 循环

三、关键里程碑（里程碑=“完成标准”+“可验证性”）
- M1：空间索引基础能力（完成）
  - 完成标准：Add/Update/Remove、Range/Bounds/Nearest/KNearest 查询与性能统计
  - 可验证性：PlayMode 冒烟测试通过；stats.TotalQueries 递增、FrameQueries 可重置、AverageQueryTime ≥ 0
- M2：Buildings 状态与查询（进行中）
  - 完成标准：BuildingState 全链路替换；查询/放置规则具备返回值与错误码
  - 可验证性：编辑器下单元测试打桩验证
- M3：Creep/Terrain 基础 API 不抛例外（进行中）
  - 完成标准：Growth/Expansion/Modification 提供可调用入口；未实现处打印告警
  - 可验证性：EditMode 单元测试覆盖常见入口
- M4：兼容层收敛（计划中）
  - 完成标准：移除 Compat 桩代码或置换为真实实现
  - 可验证性：grep 无 TODO/HACK/FIXME；Legacy/Obsolete 仅保留迁移桥
