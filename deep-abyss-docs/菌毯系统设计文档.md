## 1. 概述

菌毯系统是《深渊巢穴》游戏的特色系统，负责模拟和管理地下文明的生物基础设施 - 菌毯。菌毯作为一种活体组织，不仅是建筑的基础，也是能量传输网络和单位增益区域。本文档详细描述了菌毯系统的设计、数据结构、接口定义和实现细节。

## 2. 系统目标

- 实现动态扩张和收缩的菌毯网络
- 支持菌毯作为建筑基础和能量传输网络
- 提供菌毯对单位和建筑的增益效果
- 实现菌毯与环境的交互（如地形影响、资源吸收）
- 支持多玩家的菌毯竞争和交互
- 确保大地图上菌毯系统的高性能运行

## 5. 菌毯扩张机制

菌毯扩张是菌毯系统的核心机制，主要通过以下方式实现：

### 5.1 源点扩张

菌毯从源点（通常是建筑）向外扩张：

1. **初始创建**：在源点位置创建高密度菌毯
2. **周围扩散**：根据扩散算法向周围格子扩散
3. **密度衰减**：随着距离增加，菌毯密度逐渐降低
4. **最大范围**：每个源点有最大扩张范围限制

### 5.2 网络连接

多个菌毯源点可以形成网络：

1. **网络识别**：相邻的菌毯格子自动形成网络
2. **网络合并**：当两个网络接触时，可以合并为一个
3. **网络分裂**：当连接断开时，网络可能分裂为多个

### 5.3 环境影响

环境因素会影响菌毯扩张：

1. **地形影响**：不同地形对菌毯扩张有不同影响（如岩石阻碍，沙地减缓）
2. **资源影响**：资源丰富区域可能加速菌毯生长
3. **敌对菌毯**：不同玩家的菌毯相遇会产生竞争和抑制

## 6. 菌毯能量系统

菌毯作为能量传输网络，实现以下功能：

### 6.1 能量产生

1. **生物能核心**：专门的建筑产生生物能
2. **自然吸收**：菌毯可以从环境中缓慢吸收能量
3. **资源转化**：可以将资源转化为能量

### 6.2 能量传输

1. **网络传输**：能量可以在连接的菌毯网络中传输
2. **传输效率**：传输效率受菌毯密度和距离影响
3. **传输限制**：传输速率和总量有上限

### 6.3 能量消耗

1. **建筑消耗**：建筑运行需要消耗能量
2. **菌毯维护**：维持菌毯需要少量能量
3. **特殊能力**：某些特殊能力需要消耗大量能量

## 7. 菌毯与单位交互

菌毯对单位有多种影响：

## 9. 实现细节

### 9.1 菌毯数据存储

菌毯数据使用高效的存储结构：

1. **网格表示**：使用二维网格表示菌毯覆盖区域
2. **稀疏存储**：只存储有菌毯的格子，节省内存
3. **空间索引**：使用空间索引加速位置查询
4. **分块管理**：大地图分块管理，按需加载

### 9.2 菌毯更新算法

菌毯更新采用高效算法：

1. **增量更新**：只更新变化区域，而非整个地图
2. **优先级队列**：根据重要性排序更新任务
3. **时间间隔**：不同区域使用不同更新频率
4. **多线程处理**：使用多线程加速大规模更新

### 9.3 菌毯渲染

菌毯渲染采用优化技术：

1. **GPU实例化**：使用GPU实例化渲染大量菌毯元素
2. **LOD系统**：根据距离调整渲染细节
3. **合批处理**：合并相似区域减少绘制调用
4. **动态材质**：使用动态材质表现菌毯状态变化

## 10. 性能优化

为确保菌毯系统在大地图上保持良好性能，采用以下优化策略：

1. **空间分区**：使用四叉树或网格分区加速空间查询
2. **数据压缩**：压缩菌毯数据减少内存占用
3. **延迟更新**：非关键区域使用较低更新频率
4. **视野剔除**：只更新和渲染视野内的菌毯
5. **多线程计算**：使用Job System进行多线程计算
6. **GPU加速**：使用计算着色器加速大规模计算

### 12.2 CreepManager.Growth.cs

负责菌毯的扩张、收缩和密度演化：

```csharp
using UnityEngine;
using System.Collections.Generic;

namespace DeepAbyssHive.Creep.Managers
{
    public partial class CreepManager
    {
        // 菌毯创建和扩展实现
        public bool CreateCreepAt(Vector3 position, float initialDensity, int ownerId)
        {
            Vector2Int gridPos = WorldToGrid(position);
            
            if (_creepGrid.ContainsKey(gridPos))
            {
                // 更新现有菌毯
                CreepData data = _creepGrid[gridPos];
                
                // 如果是同一所有者，增加密度
                if (data.OwnerId == ownerId)
                {
                    data.Density = Mathf.Min(1.0f, data.Density + initialDensity);
                    _creepGrid[gridPos] = data;
                    return true;
                }
                // 如果是不同所有者，根据密度决定归属
                else if (initialDensity > data.Density)
                {
                    data.OwnerId = ownerId;
                    data.Density = initialDensity;
                    _creepGrid[gridPos] = data;
                    return true;
                }
                
                return false;
            }
            
            // 创建新菌毯
            CreepData newData = new CreepData
            {
                GridPosition = gridPos,
                WorldPosition = position,
                Density = Mathf.Clamp01(initialDensity),
                OwnerId = ownerId,
                Health = _config.DefaultCreepHealth,
                MaxHealth = _config.DefaultCreepHealth,
                State = CreepState.Growing,
                GrowthRate = _config.DefaultGrowthRate,
                DecayRate = _config.DefaultDecayRate,
                NetworkId = -1, // 暂未分配网络
                EnergyFlow = 0,
                IsConnected = false
            };
            
            _creepGrid.Add(gridPos, newData);
            
            // 尝试将新菌毯添加到现有网络
            TryConnectToNetwork(gridPos);
            
            return true;
        }
        
        public bool ExpandCreep(Vector3 sourcePosition, float radius, float growthRate, int ownerId)
        {
            Vector2Int centerGrid = WorldToGrid(sourcePosition);
            int gridRadius = Mathf.CeilToInt(radius / _gridCellSize);
            
            bool expanded = false;
            
            // 遍历半径内的所有格子
            for (int x = -gridRadius; x <= gridRadius; x++)
            {
                for (int y = -gridRadius; y <= gridRadius; y++)
                {
                    Vector2Int gridPos = new Vector2Int(centerGrid.x + x, centerGrid.y + y);
                    
                    // 检查是否在圆形范围内
                    float distance = Vector2.Distance(new Vector2(x, y) * _gridCellSize, Vector2.zero);
                    if (distance > radius)
                        continue;
                    
                    // 计算基于距离的密度
                    float densityFactor = 1.0f - (distance / radius);
                    float newDensity = _config.BaseDensity * densityFactor * growthRate;
                    
                    // 创建或更新菌毯
                    if (CreateCreepAt(GridToWorld(gridPos), newDensity, ownerId))
                    {
                        expanded = true;
                    }
                }
            }
            
            return expanded;
        }
        
        public bool RemoveCreep(Vector3 position, float radius)
        {
            Vector2Int centerGrid = WorldToGrid(position);
            int gridRadius = Mathf.CeilToInt(radius / _gridCellSize);
            
            bool removed = false;
            List<Vector2Int> toRemove = new List<Vector2Int>();
            
            // 遍历半径内的所有格子
            for (int x = -gridRadius; x <= gridRadius; x++)
            {
                for (int y = -gridRadius; y <= gridRadius; y++)
                {
                    Vector2Int gridPos = new Vector2Int(centerGrid.x + x, centerGrid.y + y);
                    
                    // 检查是否在圆形范围内
                    float distance = Vector2.Distance(new Vector2(x, y) * _gridCellSize, Vector2.zero);
                    if (distance > radius)
                        continue;
                    
                    if (_creepGrid.ContainsKey(gridPos))
                    {
                        toRemove.Add(gridPos);
                        removed = true;
                    }
                }
            }
            
            // 移除菌毯
            foreach (Vector2Int pos in toRemove)
            {
                RemoveCreepAt(pos);
            }
            
            return removed;
        }
        
        private void RemoveCreepAt(Vector2Int gridPos)
        {
            if (_creepGrid.ContainsKey(gridPos))
            {
                CreepData data = _creepGrid[gridPos];
                
                // 如果属于网络，从网络中移除
                if (data.NetworkId >= 0 && _creepNetworks.ContainsKey(data.NetworkId))
                {
                    _creepNetworks[data.NetworkId].CoveredCells.Remove(gridPos);
                    
                    // 如果网络为空，移除网络
                    if (_creepNetworks[data.NetworkId].CoveredCells.Count == 0)
                    {
                        _creepNetworks.Remove(data.NetworkId);
                    }
                }
                
                _creepGrid.Remove(gridPos);
            }
        }
        
        private Vector2Int WorldToGrid(Vector3 worldPosition)
        {
            return new Vector2Int(
                Mathf.FloorToInt(worldPosition.x / _gridCellSize),
                Mathf.FloorToInt(worldPosition.z / _gridCellSize)
            );
        }
        
        private Vector3 GridToWorld(Vector2Int gridPosition)
        {
            return new Vector3(
                gridPosition.x * _gridCellSize + _gridCellSize * 0.5f,
                0, // 假设菌毯总是在地面上
                gridPosition.y * _gridCellSize + _gridCellSize * 0.5f
            );
        }
```

```csharp
using UnityEngine;
using System.Collections.Generic;

namespace DeepAbyssHive.Creep.Managers
{
    public partial class CreepManager
    {
        // 菌毯查询实现
        public CreepData GetCreepAt(Vector3 position)
        {
            Vector2Int gridPos = WorldToGrid(position);
            
            if (_creepGrid.TryGetValue(gridPos, out CreepData data))
            {
                return data;
            }
            
            // 返回默认值表示没有菌毯
            return new CreepData
            {
                Density = 0,
                OwnerId = -1,
                NetworkId = -1,
                State = CreepState.Dead
            };
        }
        
        public float GetCreepDensity(Vector3 position, out int ownerId)
        {
            CreepData data = GetCreepAt(position);
            ownerId = data.OwnerId;
            return data.Density;
        }
        
        public List<Vector2Int> GetCreepCoverage(int ownerId)
        {
            List<Vector2Int> coverage = new List<Vector2Int>();
            
            foreach (var pair in _creepGrid)
            {
                if (pair.Value.OwnerId == ownerId)
                {
                    coverage.Add(pair.Key);
                }
            }
            
            return coverage;
        }
        
        public bool IsPositionOnCreep(Vector3 position, int ownerId)
        {
            CreepData data = GetCreepAt(position);
            return data.OwnerId == ownerId && data.Density > _config.MinimumValidDensity;
        }
        
        public int GetNetworkIdAt(Vector3 position)
        {
            CreepData data = GetCreepAt(position);
            return data.NetworkId;
        }
        
        public CreepNetworkData GetNetworkData(int networkId)
        {
            if (_creepNetworks.TryGetValue(networkId, out CreepNetworkData data))
            {
                return data;
            }
            
            return null;
        }
    }
```
