# 建筑 × 菌毯 接口契约（v0.3）
版本: 0.3
日期: 2025-08-28
作者: CodeBuddy
上游版本：_archive/2025-08/接口契约v0.2-建筑与菌毯.md

变更摘要
- 对齐空间索引 Bounds 传递口径
- 明确放置前对菌毯密度与连接性的查询

一、查询与校验
- QueryCreepDensity(bounds): float （0–1）
- IsConnectedToHive(bounds): bool
- ReserveCreepArea(bounds, durationMs): Result （避免竞态）

二、事件与回调
- OnBuildingPlaced(buildingId, bounds)
- OnBuildingRemoved(buildingId, bounds)

三、错误码
- E_CREEP_TOO_LOW（密度不足）
- E_NOT_CONNECTED（不连通）
- E_AREA_BUSY（区域被占用）

四、实现建议
- CreepQueryService 暴露密度/连通性查询（当前为 TODO，可用占位返回）
- 建筑放置前先走菌毯接口，失败短路
